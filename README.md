# Avaia By Monii — Online Store + Private Profit Dashboard

This package is prepared for simple deployment on Render. It includes the storefront, checkout, Paystack payment flow, order tracking, inventory, pending orders, revenue/profit dashboard, expenses and notifications.

## Recommended deployment

1. Create a GitHub repository and upload this folder.
2. In Render, choose **New → Blueprint** and connect the repository. Render will read `render.yaml`.
3. Enter the secret values marked `sync: false`: `ADMIN_EMAIL`, `ADMIN_PASSWORD`, `PAYSTACK_SECRET_KEY`, `PAYSTACK_PUBLIC_KEY`, `BASE_URL` and optional SMTP settings.
4. Deploy.
5. Open `/admin/login.html` for the private dashboard.

The app uses SQLite stored at `/var/data/avaia.sqlite` and the Blueprint attaches a persistent disk there. The first start automatically creates the database tables, starter products and the admin password from your environment variables; later deploys do not reset your stock. Keep the disk/database backed up.

## Paystack

Use Paystack test keys first. After testing, replace them with your live keys. Never put the Paystack secret key in frontend files. Set Paystack webhook URL to:

`https://YOUR-DOMAIN/api/paystack/webhook`

The callback URL is generated by the server from `BASE_URL`.

## Local testing

```bash
npm install
copy .env.example .env
npm run seed
npm start
```

Then open `http://localhost:3000`.

## Important

This is an ecommerce starter prepared for deployment, not a substitute for final business/payment/compliance checks. Test checkout, payment verification, webhook delivery, inventory, order status changes and email notifications before accepting real orders.
